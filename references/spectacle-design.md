# 亮眼/奇观设计：让建筑“记住”而不是“更大”

> 用户说“不够亮眼酷炫”时，不要继续加方块；先加**视觉层级**：剪影、对比、光、运动、声音。

## 1. 先做 3 个方向

| 方向 | 做法 | 风险 |
|---|---|---|
| 稳健 | 夜景灯光 + 金色收边 + 旗帜 | 容易只是“亮一点” |
| 联动 | 建筑 + 粒子/钟声 + FMBE 雕像/烛台 | 需要命令方块/性能 |
| 大胆 | 中央冠冕尖塔 + 发光玫瑰窗 + 浮空烛海 + 色彩对撞 | 容易过度/挡视线 |

选“大胆”时，仍要保留一个清晰的**主焦点**。

## 2. 奇观的 6 个杠杆

1. **剪影**：中央塔/双塔/尖刺/飞扶壁，在缩略图里能认出来。
2. **尺度对比**：主塔 1.5~2× 中殿；入口压低，内部抬高。
3. **色彩对撞**：深色石/黑石 + 金 + 青绿/海晶；强调色 10%。
4. **发光体**：sea_lantern、shroomlight、lantern、end_rod、彩玻；不要全屋一样亮。
5. **运动**：粒子（flame/soul_fire/end_rod）、烟雾（campfire）、钟声（定时）。
6. **叙事焦点**：玫瑰窗/祭坛/王座/巨钟；所有线条指向它。

## 3. 夜景教堂/大厅的做法

- 外部：檐口/扶壁/塔尖加 lantern/sea_lantern；广场 braziers；入口金门。
- 内部：吊灯/浮空烛/祭坛发光十字；彩窗内侧透光。
- **主焦点**比周围亮 2~3 档；侧廊压暗。
- 声音：钟声 10~15 秒一次；不要每 tick。
- 粒子：每 5 tick 少量；不要全屏。

## 4. 避免“土味酷炫”

- 不要把所有颜色都用上；3~5 家族。
- 不要满屋顶霓虹；只描边/焦点。
- 不要粒子全图刷；只 2~3 个点。
- 不要让中央塔挡住入口/主路径。
- 不要在生存服里放伤害性 campfire/火焰在玩家路径上。

## 5. 工程实现

- 大面积用 `fill`；灯光/装饰用 `setblock`。
- 粒子/钟声用隐藏 repeat/chain 命令方块；需要区块加载。
- 先离线渲染，再进服务器；回读关键坐标。
- 粒子/声音先小批量，观察性能。

## 6. 检查

- [ ] 3 秒剪影能认出吗？
- [ ] 主焦点是否明确？
- [ ] 颜色是否 ≤5 家族？
- [ ] 发光体是否分层？
- [ ] 运动和声音是否节制？
- [ ] 入口/主路径是否被挡？
- [ ] 服务器性能是否可接受？
