# 内饰设计：从大厅到教堂

> 参考：Sunrain 语料中的大厅/商店/教堂/酒店/图书馆/酒馆，以及 `work/gothic-church/refs/interior-board.jpg`。
> 目标：不是把家具堆满，而是让玩家**知道往哪走、看什么、在哪里停**。

## 1. 先定四件事

1. **功能**：入口/接待/主厅/侧厅/祭坛/柜台/座位/后台。
2. **动线**：主路径 2~3 格宽；不要被家具堵死；入口 3 秒能看懂。
3. **焦点**：一个主焦点（祭坛/舞台/王座/喷泉/吧台），2~3 个次焦点。
4. **层高**：至少 4 格；大厅 8~20 格；教堂中殿 20+ 格。

## 2. 参考里最有效的四招

### 2.1 大厅：拱廊 + 暖光 + 地毯

- 两侧连续拱/柱，形成透视。
- 深色木/石 + 暖色灯，地面用红/蓝地毯导向焦点。
- 雕像/喷泉/吊灯做视觉锚点。
- 家具不贴墙排满，留出中间通道。

### 2.2 长走廊/商店街：重复 + 尽端焦点

- 同一开间重复（柱/店招/灯），让空间“变长”。
- 地面用两种材质分带，标出主通道。
- 尽端放一个更大的门/雕像/招牌，避免“走不到头”。

### 2.3 剧场/教堂：中轴 + 分层 + 向上看

- 中轴从入口直指祭坛/舞台。
- 两侧侧廊/包厢/侧祭坛，制造“层次”。
- 屋顶用肋拱/梁/吊灯，把视线往上拉。
- 灯光从上方/侧面打，形成明暗，不要全屋均匀亮。

### 2.4 市场/大厅：色彩分区 + 地面图案

- 每个摊位/店铺一个主色，但控制在 3~5 家族。
- 地面用图案/地毯划分区域，不靠墙。
- 招牌/旗帜/灯串做垂直元素。

## 3. 内饰的 1/3/5 法则

- **1 个主焦点**：祭坛/舞台/王座/喷泉/吧台。
- **3 个层次**：地面（路径/图案）→ 家具（座椅/柜台/展台）→ 顶部（拱/梁/吊灯）。
- **5 步一个变化**：每 5~8 格出现柱子/灯/门/家具变化，避免长墙。

## 4. 材质与光

| 层 | 建议 |
|---|---|
| 地面 | 深色石/木 + 地毯导向；主路径和侧区不同 |
| 墙面 | 石/木/白墙；用柱/扶壁/壁龛分带 |
| 顶部 | 深色木/石肋；吊灯/梁；不要纯平 |
| 强调 | 金/铜/红/蓝；≤10% |
| 光 | 暖色 lantern/吊灯 + 冷色玻璃窗；明暗对比 |

**教堂**：深石 + 木 + 金 + 彩窗；**大厅**：暖木 + 石 + 地毯；**商店**：亮色招牌 + 木/石；**图书馆**：深木 + 书架 + 阅读灯。

## 5. 家具尺度

- 1 格 ≈ 1 米：桌 2×1，椅 1×1，床 2×1，书架 1×2，柜台 1×2。
- 座椅之间留 1 格；主通道 2~3 格；祭坛/舞台前留 3~5 格。
- 家具不要悬空/嵌墙；先做空壳，再放家具。
- 用楼梯/台阶/栅栏/活板门做细节，但注意碰撞箱。

## 6. 教堂内饰模板

```
西入口/narthex
  → 中殿 nave（中轴地毯 + 两侧 pews + 柱列）
  → 侧廊 aisles（侧祭坛/小礼拜堂/忏悔室）
  → 十字翼 transept（侧祭坛/玫瑰窗）
  → 唱诗席 choir（高背座椅 + 乐谱架）
  → 后殿 apse（台阶 + 祭坛 + 十字 + 烛台 + 马赛克）
```

- 柱子：每 8 格一跨；柱头/柱础用浅色石。
- 屋顶：横向尖拱 + 对角肋 + 脊肋；不要只做平顶。
- 光：吊灯从屋顶垂下；侧窗彩玻；祭坛烛光。
- 声/视觉：入口用深色门框，内部用暖光，形成“从暗到亮”。

## 7. 检查表

- [ ] 入口 3 秒能看出这是教堂/商店/大厅吗？
- [ ] 主路径是否 ≥2 格、无家具堵路？
- [ ] 是否有 1 个主焦点 + 2~3 个次焦点？
- [ ] 地面/墙面/顶部是否分层？
- [ ] 光源是否有明暗，而不是全屋一样亮？
- [ ] 材质是否 ≤5 家族、强调 ≤10%？
- [ ] 家具尺度/间距是否合理？
- [ ] 是否有多余的“装饰堵路”？
- [ ] 多人时是否会被家具卡住？
- [ ] 区块/实体/粒子是否可控？

## 8. 反模式

- 先摆家具，后想功能。
- 中间放喷泉/雕像，把主路径堵死。
- 全屋插火把，没有明暗。
- 每个墙面都挂画/牌子，没有留白。
- 家具贴墙一圈，中间空得发慌。
- 教堂只有长椅，没有侧祭坛/唱诗席/祭坛层次。

## 9. 高级内饰 pass

### 9.1 深窗洞，不要贴玻璃

- 5 格厚墙的玫瑰窗：外层彩玻 + 内层彩玻，中间 3 格切空；内层加石/金窗棂。
- 这样从室内看是“发光的洞”，不是贴在墙上的彩色方块。
- 单格厚墙的侧窗可以直接用玻璃当内表面。

### 9.2 用 slab 做肋拱曲线

- 尖拱公式：`yy = 30 + 7 * (1 - (|x-180|/12)^2)`。
- 用 `deepslate_tile_slab` 放曲线，`stone_brick_slab` 做第二层厚度。
- 对角肋用 slab 从柱头爬到脊；脊肋用整块，交点放金块。
- 默认 slab 是下半砖，不需要状态；方向性强的楼梯才需要 `["weirdo_direction"=...]` / `["minecraft:cardinal_direction"=...]`，先在目标版本实测。

### 9.3 教堂的“高级五件套”

1. **Rood screen**：唱诗席前的木/铁屏，中央留门，上方十字。
2. **Pulpit**：侧廊八角讲道台，木+石+金。
3. **Altar rail**：祭坛前栅栏，中央开口。
4. **Retable / mural**：祭坛后的金/彩玻/马赛克，不要空白墙。
5. **Censer**：`campfire` 放在金盆里，产生烟/氛围；`soul_campfire` 在本服 `/setblock` 回读失败，别用。注意别烧到玩家。

### 9.4 地面与光

- 侧廊用深色石+金色横带，中央红毯；十字翼做十字图案。
- 吊灯：chain 从屋顶到 y18，iron bars 横架，3 个 lantern。
- 柱边 candle / lantern；屋顶下藏 shroomlight 做暖光。
- 有明暗：祭坛最亮，侧廊次之，角落暗。

### 9.5 检查

- [ ] 玫瑰窗从室内看是否透光？
- [ ] 肋拱是否真的在屋顶下，不是悬空？
- [ ] Rood screen 是否挡住主视线/通道？
- [ ] 祭坛 rail 是否留门？
- [ ] slab/stairs 默认状态是否可接受？
- [ ] 蜡烛/营火是否会造成伤害/卡顿？
