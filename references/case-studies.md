# 参考案例：从“好看”到“可建造”

这些案例只提取规律，不复制坐标、存档或窗花。

## Tolbooth Kirk（Leonie_Ith，litematic）

- 尺度 **149×189×72**；非空气方块约 **6.6 万**。
- 类型：单塔哥特教堂；长中殿 + 一座压倒性的塔/尖塔。
- 可迁移：
  - **剪影优先**：一个最高主塔 + 一条长中殿，远看就成立。
  - **竖向节奏**：每跨扶壁/尖饰/窗，形成重复；不是一条平墙。
  - **3–5 族石料**：浅/中/深/黑 + 少量暖色点缀；不是一种白。
  - **深窗**：窗退进厚墙，有窗台/窗楣/窗棂。
  - **尖饰打断屋脊**：老虎窗/小尖塔/十字。
- 对“奶油石大盒子”的修正：先换石族，再加扶壁/尖饰，最后才加窗花。

## 圣维蕾娜修道院（Leonie_Ith）

- Java 1.20.1 与 Java 26.3 快照两个版本；大型修道院建筑群。
- 可迁移：
  - **庭院/回廊是虚空间**；长翼要挖内院/采光井，不要整栋实心。
  - 回廊用**连拱 + 柱 + 深色背墙**，让阴影读得出来。
  - 建筑群比单栋盒子更耐看：主教堂 + 附属翼 + 庭院。

## Buckingham Palace（Minecraft by anjie111）

- Java 1.21.1；新古典长立面。
- 可迁移：
  - **浅浮雕**：壁柱、檐口、窗楣、栏杆、阳台；不是哥特的 4 格深拱。
  - **水平 631**：60% 长翼、30% 中央门廊/端亭、10% 阳台/金饰。
  - **五开间中央 + 两端三开间端亭**，长立面靠节奏而不是靠雕花。
- 风格提醒：不要把所有建筑都做成哥特；新古典的深度系统不同。

## 应用

- Tolbooth 的石族混色/扶壁尖饰/深窗
- 圣维蕾娜的两座内院/回廊
- 白金汉的中央五开间/端亭节奏
