## 2026-11-13 · 旧结论被推翻：`hasitem` 其实能读 `data`

**旧结论**（基线 28 / U58 / G9）：`hasitem` 读不到物品名，只能靠「类型唯一」或「计分凭证」。

**实际情况**：`hasitem` 认四个谓词 —— `item` / `location` / `quantity` / **`data`**。
读不到的是 `CustomName` / `Lore` / 附魔，**`data`（物品损伤值）是能读的**。

```mcfunction
give @s enchanted_book 1 104
execute as @a[hasitem={item=enchanted_book,location=slot.weapon.mainhand,data=104}] run ...
```

同一类型换 `data` 就是不同物品，`data` 还能写区间（`data=1..`）。

**为什么之前会错**：`09-tricks.md` 里一直有 `hasitem={item=snowball,data=1}` 的正确用法
（手雷 / 烟雾弹 / 盾牌），但基线那条结论是另一条线总结的，两边没对齐。
典型的「文档自己打架」——所以 Z.5 第 3 条要求改之前先搜。

**已修正**：基线 28 / G9 / U58 / 十一.3（补了 `data=` 方案并提到首位）。
