# 33 · 建筑类型学：从名作到可建参数

> 用途：把“参考建筑”拆成可执行的类型卡，而不是复制外观或描述。
> 机器可读版本：`scripts/arch_style.py` 的 `ARCHETYPES`。

## 0. 怎么用

1. 先选**类型**，不要先选颜色；
2. 从类型卡提取 3–5 个硬约束（场地、序列、剖面、结构、屋顶）；
3. 至少改动 3 个条件（场地/功能/尺度/材料/母题）再做“仿作”；
4. 把约束写进 `ArchSpec` / `ArchBuilder`，不要照搬坐标；
5. 输出 front/top/iso + report，检查剪影、入口、焦点、可走性。

类型卡的五条轴：

```text
场地 / 序列 / 剖面 / 结构 / 表皮
```

任何建筑都可以先在这五轴上定位，再谈装饰。

## 0.1 风格分类总表

先按这张表选**大类**，再下钻到 §1–§7 的具体建筑卡。不要从颜色/装饰反推类型。

| 风格分类 | 核心建筑灵感 | 核心设计思路 | 关键设计方法 | 精神内核 |
|---|---|---|---|---|
| 日式建筑 | 禅宗侘寂、自然共生、战国防御、贵族茶人雅趣 | 顺应地形，以纯木构为载体，弱化人工痕迹，追求虚实相生的静谧 | 榫卯无钉、悬挑木构、回游式园林、框景借景、分层收分 | 天人合一，物哀侘寂，建筑消隐于自然 |
| 韩式建筑 | 儒家礼制、山水审美、本土丹青、实学实用 | 依山水布局，中轴彰显礼制，后苑融于自然，功能优先兼顾装饰 | 等级化丹青、歇山曲线屋顶、石造仿木、被动式通风防潮 | 礼序与自然相融，质朴中见精巧 |
| 汉式建筑 | 儒家礼乐、天人合一、官式等级、佛教空间 | 中轴对称，以材份制为统一模数，抬梁体系实现结构与美学统一 | 斗拱抬梁、材份模数、金厢斗底槽/叉柱造、举折屋面、侧脚生起 | 礼乐秩序，天人相应，结构即美学 |
| 欧美经典建筑 | 古典比例、人文主义、工业技术、绝对王权 | 以数学比例为核心，从古典柱式到工业结构，追求秩序、宏大与永恒 | 古典柱式、穹顶帆拱、黄金比例、钢铁预制装配、几何中轴园林 | 比例即美，理性与人文交织 |
| 哥特式建筑 | 宗教天国崇拜、城市共同体、向上升腾 | 以垂直向上为视觉语言，用结构解放墙体，以彩色光影营造神圣 | 尖拱+肋拱顶+飞扶壁、束柱、彩色玻璃、火焰式装饰 | 向天国延伸的石头圣经 |
| 中世纪建筑 | 宗教信仰、防御生存、东西方贸易交融 | 厚重敦实、功能优先，防御与宗教空间结合，因地就势 | 厚墙窄窗罗曼拱、拜占庭穹顶帆拱、双层城墙、依山垂直布局 | 信仰与生存的双重空间载体 |
| 庄园建筑 | 贵族权力、田园理想、家族传承 | 宅邸为核心，园林为延伸，从人工秩序过渡到自然，复合居住/社交/生产 | 古典官式立面、几何/自然式造园、层级化功能、山水借景 | 权力与品味的空间宣言 |

使用规则：

- **日式**：先定“自然/地形/水体”，再定木构和框景；不要先做白墙深瓦。
- **韩式**：先定“中轴+月台/后苑”，再定丹青和青瓦；不要把韩式做成中国宫殿。
- **汉式**：先定“开间/材份/台基”，再定斗拱和屋顶；不要只贴大屋顶。
- **欧美古典**：先定“比例/柱式/轴线”，再定装饰。
- **哥特**：先定“骨架/垂直/光”，再定玫瑰窗和尖塔。
- **中世纪**：先定“地形/防御层次”，再定罗曼/拜占庭符号。
- **庄园**：先定“轴线/园林/功能分区”，再定立面风格。

## 1. 日本

### 姬路城（日式城堡）

- **场地**：台地/石垣，外壕 → 本丸逐层抬高
- **序列**：螺旋折返参道，全程暴露在箭楼射程内
- **剖面**：天守逐层收分，多重檐，重心低
- **结构**：木构 + 倾斜石垣（野面积み），白灰墙
- **表皮**：白墙 + 深瓦，真假箭窗，檐下落石孔

可建参数：

```text
台基坡度 60–75°
天守 5 层，逐层收 8–15%
参道至少 2 次折返
白墙:深瓦 = 7:3
箭窗成组，不要整面均匀
```

避免：只做白色方盒 + 绿屋顶；没有石垣和折返序列。

### 金阁寺（临水楼阁）

- **场地**：池岸，低视点，建筑贴水
- **序列**：岸边步道 → 对岸借景 → 倒影
- **剖面**：三层，三种风格叠加
- **结构**：木构，底层寝殿造，上两层金箔
- **表皮**：金箔 + 白木 + 深瓦；屋顶凤凰

可建参数：

```text
水面占比 ≥ 35%
建筑底标高接近水面 0–1 格
三层风格必须可读：素木 / 佛堂 / 金顶
主视点在对岸，不在正门
```

避免：把金阁做成金色盒子；没有水面和倒影。

### 清水寺（悬崖木构）

- **场地**：悬崖，顺应等高线
- **序列**：山门 → 本堂 → 悬空舞台
- **剖面**：舞台悬挑 13 米，下方架空
- **结构**：榉木立柱、榫卯、无钉；桁架悬挑
- **表皮**：原木 + 深瓦，舞台无墙

可建参数：

```text
悬挑 ≥ 建筑进深 1/3
立柱沿崖分层，不落同一平面
舞台下方留空腔/共鸣
本堂、舞台、钟楼沿等高线错落
```

避免：把舞台做成普通平台；没有悬崖高差。

### 东大寺（大佛尺度）

- **场地**：寺院中轴，七堂伽蓝
- **序列**：南大门 → 中门 → 大佛殿
- **剖面**：九开间四进深，室内以佛像为尺度
- **结构**：抬梁式，多层巨木梁，重檐斗拱
- **表皮**：深木 + 重檐庑殿，斗拱雄大

可建参数：

```text
主殿开间 7–9
佛像/主焦点高度 ≥ 殿高 2/3
入口先压暗，进入后仰视
中轴两侧配钟楼/经藏
```

避免：先做巨大空壳，没有主焦点尺度。

### 桂离宫（数寄屋/回游园）

- **场地**：池岸，回游式园林
- **序列**：曲折步道，步移景异
- **剖面**：小体量，低基座，贴合人体
- **结构**：原木、草葺、推拉门
- **表皮**：素木、白墙、榻榻米；不施彩绘

可建参数：

```text
建筑高度 ≤ 2 层
单室开间 3–5
每 20–30 格一个景观节点
门/窗/檐口形成框景
```

避免：把日式做成大屋顶宫殿；失去人体尺度。

## 2. 韩国

### 景福宫（宫殿）

- **场地**：南北中轴，前朝后寝
- **序列**：光化门 → 弘礼门 → 勤政门 → 勤政殿
- **剖面**：月台抬高，重檐歇山
- **结构**：抬梁式，斗拱简化，露明梁架
- **表皮**：丹青（红绿蓝金）+ 青灰瓦 + 石月台

可建参数：

```text
中轴严格对称
主殿重檐歇山，配殿悬山/歇山
月台 2 层，中央御道
丹青只用于殿身/檐下，不刷满墙
```

避免：用中国宫殿的金色屋顶替代青瓦；忽略月台高差。

### 佛国寺（石造寺院）

- **场地**：山地台地，双层石坛
- **序列**：山门 → 大雄殿 → 极乐殿
- **剖面**：台基抬高，双塔并立
- **结构**：花岗岩干砌台基，木构殿身
- **表皮**：石台基 + 木殿 + 石塔

可建参数：

```text
双层石台基，高差 2–4 格
双塔一简一繁，分列主殿前
廊庑围合，形成封闭佛国
石构件仿木构（斗拱/檐口）
```

避免：只放两座相同塔；没有石台基层次。

### 昌德宫（因山就势）

- **场地**：后山，自然山林
- **序列**：宫殿区 → 秘苑 → 亭阁/莲塘
- **剖面**：随等高线高低错落
- **结构**：木构，临水亭阁半架水
- **表皮**：原木素柱，歇山顶，不追求中轴

可建参数：

```text
中轴允许弯曲/偏移
后苑保留原生树/石
3 处水体，10+ 亭台节点
亭阁一半临水/一半架水
```

避免：把秘苑做成法式几何园；砍平山体。

### 水原华城（要塞城市）

- **场地**：山脊/河流，5.7 km 城墙
- **序列**：城门 → 瓮城 → 马道 → 敌楼
- **剖面**：城墙随地形起伏，高处敌楼、低处水门
- **结构**：石基 + 夯土包砖
- **表皮**：女墙/雉堞 + 棱堡炮台

可建参数：

```text
城墙沿地形，不强行拉直
4 座主城门，瓮城/水门
塔楼/炮台形成交叉火力
墙顶马道 ≥ 2 格
```

避免：平原上画一圈方墙；没有地形和交叉火力。

### 海印寺藏经板殿（被动环境）

- **场地**：山谷，两殿并排
- **序列**：前院 → 法宝殿/修多罗殿
- **剖面**：地面抬高 1 m，架空通风
- **结构**：木构 + 炭灰/黏土/沙多层地面
- **表皮**：极简歇山，不施彩绘

可建参数：

```text
双殿并排，中间通风巷
南北窗面积差 2:1
地面抬高 + 架空层
出檐深远，保护墙体
```

避免：把藏经殿做成华丽佛殿；忽略通风/防潮。

## 3. 中国

### 佛光寺东大殿（唐）

- **场地**：寺内高台
- **序列**：山门 → 庭院 → 东大殿
- **剖面**：金厢斗底槽，内外两圈柱
- **结构**：材份制，七铺作双抄双下昂
- **表皮**：单檐庑殿，出檐近 4 m，无天花板

可建参数：

```text
平面“回”字：内槽佛坛 + 外槽礼拜
斗拱高 ≈ 柱高 1/2
出檐 ≥ 3 格
屋顶举折平缓，脊线柔和
```

避免：用明清细斗拱/高耸屋顶代替唐构。

### 应县木塔（辽）

- **场地**：城中心
- **序列**：塔基 → 明层 → 暗层
- **剖面**：双层套筒，明五暗四
- **结构**：叉柱造，54 种斗拱
- **表皮**：全木，逐层收分

可建参数：

```text
外五层/内九层（明五暗四）
内外双筒，暗层斜撑
每层收分 2–5%
斗拱随位置变化，不重复一种
```

避免：只做五层木盒；没有暗层和收分。

### 高颐墓阙（汉）

- **场地**：墓道
- **序列**：主阙 + 子阙
- **剖面**：阙基/阙身/阙楼/阙顶
- **结构**：石仿木
- **表皮**：浮雕车马/神兽/斗拱

可建参数：

```text
子母阙高低错落
石材复刻木构：柱/枋/斗拱/瓦当
分层浮雕，不要整面平刻
庑殿顶，脊线平直
```

避免：把阙做成两根石柱；没有阙楼/屋顶。

### 独乐寺观音阁（辽）

- **场地**：寺内
- **序列**：山门 → 观音阁
- **剖面**：外二内三，空井贯通
- **结构**：暗层斜撑，侧脚/叉柱
- **表皮**：重檐歇山

可建参数：

```text
中央空井贯通 3 层
佛像高度贯穿阁身
暗层做刚性层
立柱侧脚，逐层收分
```

避免：把阁做成三层楼板；没有空井。

### 南禅寺大殿（唐）

- **场地**：山村
- **序列**：小院 → 大殿
- **剖面**：三间四椽，12 柱
- **结构**：四椽栿通檐用二柱，五铺作
- **表皮**：单檐歇山，月梁，素木

可建参数：

```text
面阔 3 间，进深 4 椽
内部无多余柱
斗拱高 ≈ 柱高 1/3–1/2
举高:进深 ≈ 1:5
```

避免：小殿套大殿比例；斗拱过密。

## 4. 欧美古典

### 帕特农神庙（希腊）

- **场地**：卫城高地
- **序列**：山门 → 前廊 → 内殿
- **剖面**：围柱式，内外两圈
- **结构**：多立克柱式，无柱础
- **表皮**：大理石，檐壁/山花雕刻

可建参数：

```text
长宽比 ≈ 4:9
柱高:柱径 ≈ 9:4
基座中央微隆
角柱加粗、角开间缩小
柱身收分/卷杀
```

避免：用罗马券柱式替代希腊梁柱；忽略视差修正。

### 万神庙（罗马）

- **场地**：城市广场
- **序列**：门廊 → 圆厅
- **剖面**：单一圆形空间 + 穹顶
- **结构**：分级骨料混凝土，墙厚 6 m
- **表皮**：穹顶凹格 + 中央 oculus

可建参数：

```text
穹顶直径 = 内部高度
墙厚 ≥ 穹顶半径 1/5
凹格 5 排 × 28
顶部开 8–9 m 圆洞
地面微凸排水
```

避免：把万神庙做成矩形教堂；穹顶无减重层次。

### 圣彼得大教堂（梵蒂冈）

- **场地**：中轴广场
- **序列**：椭圆广场 → 梯形过渡 → 拉丁十字
- **剖面**：双层穹顶 + 中厅
- **结构**：肋架穹顶，巨柱式
- **表皮**：科林斯巨柱，金装饰

可建参数：

```text
穹顶直径 ≈ 42 m
中厅 ≈ 180 m
椭圆广场 + 四排柱廊
巨柱贯穿两层
```

避免：只做穹顶；忽略广场/过渡空间。

### 凡尔赛宫（法国）

- **场地**：东西中轴，园林延伸
- **序列**：前庭 → 镜厅 → 园林 → 大运河
- **剖面**：三段式立面，主层居中
- **结构**：石/砖，木屋架
- **表皮**：古典柱式 + 镜厅 + 几何园林

可建参数：

```text
中轴 ≥ 2 km（游戏内按比例缩）
镜厅一侧窗、一侧镜
园林几何修剪
国王居室在中轴
```

避免：只做宫殿盒子；没有轴线园林。

### 埃菲尔铁塔（工业）

- **场地**：城市广场
- **序列**：四腿 → 一层 → 二层 → 顶层
- **剖面**：收分桁架，四条腿合拢
- **结构**：镂空铁桁架，铆钉预制
- **表皮**：结构即装饰

可建参数：

```text
底部四腿外张，一层合拢
三层平台
截面随高度减小
斜撑形成三角稳定
```

避免：实心塔身；忽略风荷载曲线。

## 5. 哥特

### 巴黎圣母院

- **场地**：城市岛
- **序列**：西立面三门 → 中厅 → 唱诗班
- **剖面**：六分肋拱，飞扶壁
- **结构**：尖拱 + 肋拱 + 飞扶壁
- **表皮**：玫瑰窗 + 双塔

可建参数：

```text
西立面三段式
双塔 + 玫瑰窗
中厅高宽比 ≥ 2.5:1
飞扶壁跨侧廊
```

### 科隆大教堂

- **场地**：城市中心
- **序列**：西立面 → 五进厅堂
- **剖面**：双尖塔 157 m，中厅 43 m
- **结构**：束柱 + 飞扶壁
- **表皮**：尖塔/小尖塔/雕刻

可建参数：

```text
双塔高 ≈ 中厅 3.5×
五进式（中厅 + 双廊）
束柱从地到拱顶
飞扶壁装饰化
```

### 米兰大教堂

- **场地**：城市广场
- **序列**：西立面 → 中厅 → 后殿
- **剖面**：火焰式，135 尖塔
- **结构**：白色大理石，密集扶壁
- **表皮**：尖塔森林 + 花窗

可建参数：

```text
屋顶尖塔群，高低错落
白色石材
立面几乎无空白
尖拱/花饰/雕像密集
```

### 亚眠大教堂

- **场地**：城市
- **序列**：三门 → 中厅 → 十字 → 后殿
- **剖面**：中厅 42.3 m，宽 15 m
- **结构**：四分肋拱，束柱
- **表皮**：三座门雕刻

可建参数：

```text
中厅高:宽 ≈ 2.8:1
三门分别叙事
四分肋拱
侧廊两层
```

### 威斯敏斯特教堂

- **场地**：伦敦
- **序列**：西立面 → 中厅 → 亨利七世礼拜堂
- **剖面**：扇形拱顶
- **结构**：垂直哥特，厚重双塔
- **表皮**：大窗 + 扇形拱

可建参数：

```text
拉丁十字
扇形拱顶/垂饰
双塔方正，非尖锥

```

## 8. 山水 / 园林类型

建筑类型决定“房子长什么样”，山水类型决定“房子放在什么世界里”。

两者要成对选，不要只做建筑、不做场地。

### 8.1 园林分类总表

| 类型 | 核心灵感 | 设计思路 | 核心手法 | 精神内核 |
|---|---|---|---|---|
| 日式山水庭园 | 禅宗冥想、海岛地貌、侘寂 | 小中见大，留白，弱化人工 | 池泉回游、枯山水、借景框景、低干预植物 | 天人合一，物哀侘寂 |
| 韩式山水苑囿 | 道家天人合一、儒家比德、多山地形 | 不造山水，借山水，保留原生地形 | 因山后苑、自然莲塘、四季亭、色彩呼应 | 礼序与自然相融 |
| 中式写意园林 | 道法自然、文人山水画、比德 | 虽由人作，宛自天开；可居可游可赏 | 叠山理水、院墙回廊、漏窗框景、季相植物 | 诗画一体，写意不写实 |
| 欧美自然风景园 | 浪漫主义、田园牧歌、反几何 | 模仿自然、升华自然，如画风景 | 疏林草地、自然水体、风景建筑、视线通廊 | 如画、沉浸、怀古 |
| 哥特宗教山水 | 伊甸园、修道院隐修、象征主义 | 中庭圣园 + 山地台地，实用与象征并重 | 回廊中庭、水井/喷泉、药草园、象征植物 | 神圣、内敛、劳作即修行 |
| 中世纪防御山水 | 防御、生存、领地 | 山水即屏障，功能优先 | 天然险要、护城河/水门、生产性外围 | 信仰与生存 |
| 庄园自然山水 | 贵族权力、田园理想、领地 | 宅邸为中心，圈层过渡 | 几何→自然→生产、轴线统领、生产即景观 | 权力与品味 |

### 8.2 类型卡

#### 日式山水庭园

- **场地**：池泉/枯山水/借景，小尺度
- **序列**：曲折步道，移步换景
- **水**：不规则池岸，池中石岛
- **石**：石组不等边三角形，主石/副石/添石
- **植物**：松/枫/苔/蕨，低修剪
- **建筑**：茶亭/桥/门洞作为框景

可建参数：

```text
水面 25–40%（池泉）
枯山水白砂 + 石组，不用水
石组 3/5/7 块，忌等距
步道至少 3 次转折
每个转折有对景/框景
```

避免：把枯山水做成白沙空地；石组排成直线；植物修剪成几何球。

#### 韩式山水苑囿

- **场地**：背山/多山，保留原生林
- **序列**：宫殿 → 后苑 → 山腰亭
- **水**：自然汇水莲塘，自然岸线
- **植物**：原生树/荷/苇
- **建筑**：小型亭阁，半隐于林

可建参数：

```text
后山保留 ≥60% 原生植被
水体自然曲线，无硬质驳岸
四季亭按高程分布
建筑体量小，屋顶半露
```

避免：把后苑做成法式几何园；砍山填谷。

#### 中式写意园林

- **场地**：宅院/城市园，墙内造山
- **序列**：门 → 障景 → 院 → 主景 → 后院
- **水**：池/溪/涧/瀑/泉，收放对比
- **石**：太湖石/黄石，峰峦洞壑，瘦透漏皱
- **建筑**：亭台楼阁榭舫，依山傍水
- **植物**：松竹梅/荷/玉兰/海棠，按画意

可建参数：

```text
园中有园 ≥3 个院落层次
水体有收有放：大池 + 窄涧
假山可穿行/登临
漏窗/门洞框景
建筑不遮挡主山水视线
```

避免：假山做成石头堆；水面一眼望穿；建筑压过山水。

#### 欧美自然风景园

- **场地**：起伏草地/林地/湖
- **序列**：弯曲步道，视线通廊
- **水**：自然湖岸/溪流/瀑布
- **植物**：孤植大树/丛植/疏林草地
- **建筑**：神庙/废墟/石桥/小屋作为焦点

可建参数：

```text
无直线几何花坛
草坪 ≥40%
湖岸自然曲线
每 60–100 格一个风景焦点
视线终点有山/塔/桥
```

避免：把自然园做成几何园；焦点过多。

#### 哥特宗教山水

- **场地**：修道院/教堂旁，山地台地
- **序列**：回廊中庭 → 台地园 → 山林
- **水**：中庭水井/喷泉
- **植物**：药草/香草/玫瑰/百合/松柏
- **建筑**：回廊、台地挡墙、小礼拜堂

可建参数：

```text
方形回廊中庭
中心水井/喷泉
药草/香草分块种植
台地沿山势分层
```

避免：把修道院园做成普通花园；没有回廊和水井。

#### 中世纪防御山水

- **场地**：山顶/潮汐岛/悬崖/河湾
- **序列**：外围生产带 → 护城河 → 城墙 → 城堡
- **水**：天然水体 + 人工护城河/水门
- **植物**：菜园/果园/牧场/猎林
- **建筑**：城墙/塔楼/水门

可建参数：

```text
优先利用天然高差/水体
护城河环绕，水门控制
墙外有菜园/果园/牧场
水井/蓄水池在城内
```

避免：平原上画方墙；护城河无水源。

#### 庄园自然山水

- **场地**：大领地，宅邸居中
- **序列**：宅邸 → 几何花园 → 自然园 → 生产林地
- **水**：喷泉/运河 → 自然湖/溪
- **植物**：修剪绿墙 → 疏林草地 → 原生林
- **建筑**：宅邸/亭/神庙/农场

可建参数：

```text
三圈层：几何 / 自然 / 生产
主景观轴从宅邸向外
近宅对称，远宅自然
生产用地也做景观
```

避免：全园几何；或全园自然，没有权力轴线。

### 8.3 建筑 × 山水联动

| 建筑类型 | 推荐山水 | 结果 |
|---|---|---|
| 日式城堡 | 池泉回游 + 借景 | 白鹭天守浮于池面/山林 |
| 日式楼阁 | 池泉 + 倒影 | 金阁的水镜 |
| 日式悬崖堂 | 借景 + 悬挑 | 清水舞台俯瞰 |
| 韩式宫殿 | 后苑 + 自然莲塘 | 宫在山中 |
| 韩式寺院 | 石台 + 山林 | 佛国净土 |
| 汉式佛寺 | 写意园 + 前庭 | 寺园一体 |
| 哥特教堂 | 修道院中庭 + 台地 | 神圣花园 |

## 10. 反模式

- 只抄颜色/符号，不抄场地/序列/剖面；
- 把日式城堡做成白墙 + 绿锥顶；
- 把哥特做成尖顶贴片，没有飞扶壁/肋拱；
- 把中式做成大屋顶，没有开间/斗拱/台基；
- 把韩式做成中国宫殿，忽略月台/丹青/青瓦；
- 把所有园林做成法式几何；
- 只做正立面，不做 45° 剪影和背面；
- 只做建筑，不做场地/山水，建筑像悬浮在空地上；
- 把枯山水做成白沙空地，或把中式假山做成石头堆；
- 自然风景园里放中轴几何花坛。
