## Design notes

- All command blocks are always active; the 15x6x9 structure fits one chunk column at 64 200 0 and needs no tickingarea when the spawn chunk is loaded.
- UI is plain title/actionbar text with § colors; no camera/inputpermission/fog.
- State: sbm 0=closed 1=main 2=sub 3=action; sbsel 0..3; sbpage 1..10; sbg 0=idle / group id.
- Look-up/down is edge-detected with sblook/sbdown.
- The setup row is idempotent and runs once per second.
