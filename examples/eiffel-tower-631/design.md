# 埃菲尔铁塔 · 631 / 黄金比例版

> 中心 `(300,0,300)`，基座 64×64，结构高 192，旗顶 199。
> 设计顺序：先体块关系，再视觉焦点，最后细节。不是先堆铁艺。

## 1. 631：三层体块

| 段 | 高度 | 占比 | 内容 | 视觉重量 |
|---|---:|---:|---|---|
| 基座 | y 0–115 | 60% | 四条重腿、四面大拱、第一平台 | 最重：深色、实体柱础、粗腿 |
| 塔身 | y 115–173 | 30% | 收分格构、第二平台 | 中：重复箍/斜撑，密度降低 |
| 塔冠 | y 173–199 | 10% | 观景舱、金冠、尖顶、天线/旗 | 最亮、最密：金/玻璃/灯 |

631 同时用于：

- **体量**：60% 基座 / 30% 塔身 / 10% 塔冠；
- **配色**：60% 深色石铁 / 30% 黑石与铁栏 / 10% 金、玻璃、灯；
- **细节密度**：基座大形，塔身重复，塔冠重点刻画；
- **疏密**：底部拱洞留空，塔身格构均匀，塔冠收束加密。

## 2. 黄金比例

总高 `H=192`：

| 控制线 | 高度 | 比例 | 作用 |
|---|---:|---:|---|
| 第一平台 | y=73 | 0.382 H | 基座完成、塔身开始 |
| 第二平台 | y=119 | 0.618 H | 塔身中段收分节点 |
| 塔冠 | y=173 | 0.90 H | 进入最后 10% |
| 旗顶 | y=199 | — | 视觉终点 |

宽度：基座 64 → 第一平台 40 → 第二平台 28 → 塔冠 14。  
第一平台/基座 ≈ 0.625，第二平台/第一平台 ≈ 0.70；比严格 0.618 略宽，是为了让平台在远看时仍可读。

## 3. 视觉重量与平衡

- **重**：四条腿底部 22 格做实，7×7 柱础，深色 `polished_deepslate` / `deepslate_tiles`。
- **轻**：塔身上部用 `iron_bars` 斜撑和细角柱，越往上越透。
- **稳定**：严格四轴对称，中心线从喷泉、拱心、塔身、尖顶、旗杆一穿到底。
- **杠杆**：顶部金冠虽小，但离中心最远，用金色/海晶灯把它做成最终焦点；底部大拱用深色重量压住。
- **颜色重量**：深色 > 浅色；纯金只给塔冠和拱心，不大面积铺。

## 4. 视线引导

1. **中轴**：南入口 → 喷泉 → 大拱 → 塔心 → 尖顶 → 旗。
2. **四腿 + 大拱**：把塔心框住，形成“门”的取景。
3. **收分格构**：四条斜边把视线向上收。
4. **平台水平带**：第一、第二平台给视线一个停顿，再继续向上。
5. **塔冠**：金冠、玻璃舱、海晶灯、三色旗，作为最终视觉落点。

## 5. 结构

| 段 | 做法 |
|---|---|
| 柱础 | 四角 9×9 深色台，上压 7×7 装饰石 |
| 四条腿 | y1–73，中心距 `d=8+18(1-t)^1.25`，7×7 收至 5×5；底部 22 格实、上段格构 |
| 四面大拱 | 半圆拱，跨 36，高 29；拱心石金 + 海晶灯 |
| 第一平台 | y73，40×40，下弦斜撑，栏杆灯带，四角玻璃亭 |
| 塔身 | y74–172，宽度 `16(1-t)^0.85+2`，四角柱 + 每 4 格箍 + 每 8 格 X 撑 |
| 第二平台 | y119，28×28，外挑水平带 |
| 塔冠 | y173，14×14 玻璃舱 + 金环 + 四角金饰 |
| 尖顶 | y181–188 收成 1×1 |
| 天线/旗 | 189–193 金杆/灯，194–199 三色旗 |

## 6. 材质（60/30/10）

| 层级 | 方块 | 作用 |
|---|---|---|
| 60% 深色主体 | `deepslate_tiles`, `polished_deepslate` | 塔腿、塔身、结构带 |
| 30% 中景 | `polished_blackstone`, `iron_bars`, `smooth_stone` | 平台、地面、格构 |
| 10% 强调 | `gold_block`, `sea_lantern`, `glass` | 金冠、拱心、灯带、观景舱 |

点缀：`chiseled_deepslate` 做拱脚/装饰带；`grass_block`/`oak_leaves` 只放在四角花园，不抢塔。

## 7. 场地

- 88×88 深色石广场，中央 72×72 浅石/黑石铺地。
- 十字中轴用 `chiseled_deepslate` 和金线；南端喷泉作为入口端景。
- 四角花园/树/长椅/路灯，尺度比塔小，避免抢焦点。
- 入口门柱 + 灯，3 秒识别。
